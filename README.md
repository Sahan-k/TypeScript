# TypeScript Inventory Management – AWT Assignment

## Overview

This project is developed as part of the Advanced Web Technologies assignment.
It demonstrates important TypeScript features by implementing a simple product
inventory example.

## Concepts Implemented

- TypeScript primitive data types
- Arrays and union types
- Functions with typed parameters and return values
- Default function parameters
- Array `map()` and `filter()` methods
- Block and function scope
- Interfaces and optional properties
- Interface extension
- Product discount calculation
- TypeScript compiler error demonstration

## Project Files

- `src/inventory.ts` – Main TypeScript program
- `dist/inventory.js` – Compiled JavaScript file
- `inventory-error-demo.ts` – Demonstration of TypeScript errors
- `tsconfig.json` – TypeScript compiler configuration
- `package.json` – Project configuration and dependencies
